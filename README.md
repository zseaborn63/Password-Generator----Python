# Password-Generator----Python
A password generator for a new age!
Inspired by [DinoPass](https://www.dinopass.com/), this password generator uses multiple words as the base for a password.  Then some obfuscation is sprinkled on top to attempt to make it secure!  This is made possible by [The Random Word ApI](https://random-word-api.herokuapp.com/home) in order to return 3 words as the base of the password.
